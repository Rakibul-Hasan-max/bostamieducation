# 🎓 Bostami Education

Bostami Education is a modern, premium, and feature-rich Learning Management System (LMS) designed to deliver a seamless education experience. Powered by Next.js, React, Tailwind CSS, and AI, this platform caters to students, teachers, and administrators alike, bringing interactive learning into the digital era.

---

## 🎯 Project Vision

The primary objective of **Bostami Education** is to create a dynamic, modern, and AI-powered Learning Management System. The platform empowers students to access high-quality live classes, enroll in online courses, and complete automated examinations. Simultaneously, teachers are provided with powerful administration and grading tools, while an integrated AI Tutor offers students instant, context-aware assistance.

---

## 🚀 Key Features

### 1. 📚 Online Courses
* **Interactive Lessons:** Rich-text content, high-quality video integration, and downloadable resource materials.
* **Progress Tracking:** Auto-saving student progress across lectures, modules, and courses.
* **Review & Ratings:** Student feedback loop with reviews, ratings, and recommendations.

### 2. 🎥 Live Classes
* **Real-time Streaming:** Integrated high-quality, low-latency live class streaming.
* **Interactive Classrooms:** Live chat, raise-hand features, and screen sharing tools.
* **Class Archives:** Automatically recorded live sessions for offline playback and review.

### 3. 📝 Exam System
* **Diverse Question Types:** Support for Multiple Choice Questions (MCQs), descriptive answers, and short quizzes.
* **Timed Assessments:** Dynamic countdown timer with auto-submit capabilities to ensure integrity.
* **Instant Results:** Automatic grading for MCQs with detailed explanations of correct answers.

### 4. 🗂️ Learning Management System (LMS)
* **Course Builder:** Intuitive drag-and-drop course creator for teachers and admins.
* **Content Hierarchy:** Well-organized categories, learning paths, prerequisites, and modules.
* **Resource Directory:** Secure document storage for worksheets, notes, and extra study guides.

### 5. 📊 Student Dashboard
* **Personalized Hub:** View active courses, daily schedules, and overall learning progress.
* **Performance Analytics:** Visual graphs and statistics of exam performance and class attendance.
* **Task Management:** Deadlines, upcoming exams, and scheduled live lectures.

### 6. 🧑‍🏫 Teacher Portal
* **Student Overview:** Real-time analytics on student completion rates, engagement, and performance.
* **Grading Center:** Dedicated interface to review manual exam submissions and assignments.
* **Announcement Broadcast:** Direct communication system with students via custom notices.

### 7. 🤖 AI Tutor
* **24/7 Support:** Instant clarification on course concepts, syntax help, and calculations.
* **Context-Aware Assistance:** Tailored guidance matching the specific topic or slide the student is currently viewing.
* **Study Buddy:** Interactive quizzes generated on-the-fly by the AI to reinforce learning.

### 8. 📜 Certificates
* **Automated Generation:** Dynamic PDF/image certificate generation upon course completion.
* **Verification Portal:** Public verification link using unique cryptographic IDs for authenticity.
* **Social Sharing:** Direct integration to share certificates on LinkedIn, Twitter, and other professional platforms.

## 💻 Tech Stack

The application is built using modern, highly performant web technologies:

* **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
* **UI Library:** [React 19](https://react.dev/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Animation:** [Framer Motion](https://www.framer.com/motion/)
* **Form Handling:** [React Hook Form](https://react-hook-form.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Language:** [TypeScript](https://www.typescriptlang.org/)

## 🛠️ Getting Started

Follow these steps to run the project locally on your machine:

### 1. Clone the repository
```bash
git clone https://github.com/Rakibul-Hasan-max/bostamieducation.git
cd bostamieducation
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
